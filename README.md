# Diameter Measurement of Object in Image

A MATLAB-based image processing project that measures the diameter of an object from an image.

## Project Description

This project uses MATLAB image processing techniques to identify an object in an image and calculate its diameter in pixels. The image is processed through color-based segmentation, thresholding, noise removal, and region analysis.

## Technologies Used

- MATLAB
- Image Processing Toolbox
- Image Segmentation
- Image Thresholding
- Region Properties

## Working

1. Import the object image into MATLAB.
2. Convert and analyze the RGB image.
3. Perform color-based image segmentation.
4. Apply image thresholding to separate the object from the background.
5. Remove unwanted noise from the binary image.
6. Identify the object as a connected region.
7. Use `regionprops` to obtain the MajorAxisLength.
8. Display the measured diameter in the MATLAB Command Window.

## Output

The calculated diameter of the object is approximately **170 pixels**.

## Objective

- To measure the diameter of an object from an image.
- To understand basic image processing techniques.
- To implement image segmentation and thresholding.
- To remove noise and identify the required object.
- To calculate object dimensions using MATLAB.
